# 小脑（XiaoNao）— 本地待办 + 桌面小组件

一个**纯本地、不联网**的极简待办 App，主打「手机桌面小组件」：把待办放在桌面，点一下就能勾选完成。
功能刻意做得很简单，适合学习 / 参赛，不考虑商业化。

- 应用名：**小脑**
- 平台：Android（minSdk 21，也就是 Android 5.0 以上都能装）
- 技术：Kotlin + Jetpack Compose（界面） + 传统 AppWidget / RemoteViews（桌面小组件） + Room（本地数据库）
- 数据：全部存在手机本地（Room 数据库），不上传任何服务器

---

## 功能

- 添加待办、勾选完成 / 取消、删除
- **桌面「+ 添加」一键唤起透明弹窗，不进 App 也能记一条待办**
- **App 内一键创建桌面小组件**：顶栏「＋桌面」按钮调用系统 App Widget Pinning，点一下确认即钉到桌面（Android 8.0+，且不依赖配置页，直接显示全部未完成）
- 桌面小组件：显示**未完成**待办列表，**在桌面上点一下即可勾选完成**，点标题打开 App
- App 内一键「清空已完成」
- 纯本地、不联网，深色模式跟随系统

### v1.1 新增

- **到期提醒**：给待办设到期时间，到点弹出通知（精确闹钟；Android 13+ 首次会请求通知权限，设备重启后自动重排）
- **分类标签**：无 / 工作 / 学习 / 生活 四色分类，App 内和桌面小组件都用颜色区分
- **正式图标 + 空状态引导**：替换默认占位图标；小组件空时显示「轻触上方 ＋ 添加第一条」引导

### v1.2 新增

- **编辑已存在待办**：点列表里任意一条即可弹出编辑框，改文字 / 分类 / 到期（到期改动会同步重排提醒闹钟）
- **滑动删除 + 撤销**：在列表项上左右滑动删除，底部自动弹出「撤销」；误删可一键恢复（含原分类、到期与提醒）
- **桌面小组件分类色条**：小组件里每条待办左侧按分类上色（无 / 工作 / 学习 / 生活），一眼区分；点条目即可勾选完成
- （注：v1.2 曾做「添加时选分类」配置页，因在部分国产 Launcher 上会导致「无法添加小部件」，v1.3.3 起已移除；**v1.6 改用 App 内「小组件设置」的方式把分类筛选做了回来**，见下文）

### v1.3 新增

- **数据备份 / 恢复（JSON）**：右上角「⋮」菜单 →「导出备份」会把全部待办写成 JSON 文件并调起系统分享（可发微信/存网盘）；「导入备份」用系统文件选择器挑一个之前导出的 .json，按 id 合并恢复。纯本地、不需要任何云账号
- **搜索**：顶部搜索框按标题实时过滤，和分类筛选、置顶排序可叠加使用
- **置顶**：长按列表项即可置顶 / 取消置顶（编辑框里也有开关）；置顶的待办排在最前，标题前带 📌，桌面小组件里同样置顶显示

> 暂未做：云同步、手动拖拽排序。后续可逐步加（参考调研报告里的 LiteTask / cl-todo-app）。

### v1.3.1 – v1.3.3 修复记录

- **v1.3.1**：修复首次安装/覆盖升级后 App 直接闪退——根因是 v1.1 给待办加了「到期 / 分类」字段却漏升数据库版本，旧库与新表结构对不上，Room 打开即崩。重做迁移（逐列检测补全，并加 fallback 兜底），升级不再丢数据。
- **v1.3.2**：尝试修复桌面小组件「无法添加小部件」灰色块，但把 `setRemoteAdapter` 的版本分界写反了（老系统误用 API 31 才新增的三参数方法），反而加剧崩溃。
- **v1.3.3**：彻底修复小组件添加失败——
  1. 移除 widget 的 `android:configure` 配置页（国产 Launcher 对 configure 兼容性差，是「无法添加小部件」的主因之一）；
  2. `setRemoteAdapter` 统一用全版本兼容的两参数版本（API 11+ 即可）；
  3. `updateWidget` 外层包 try-catch，任何异常都兜底显示一个带标题的空框架，杜绝整块变灰。
  功能影响：添加小组件不再弹「选分类」页，组件统一显示全部未完成待办（分类色条仍在）；App 内分类筛选不受影响。

### v1.4 新增

- **App 内一键创建桌面小组件**：顶栏新增「＋桌面」按钮，调用 Android 系统的 App Widget Pinning（`AppWidgetManager.requestPinAppWidget`），点一下确认就把「小脑」小组件钉到桌面，省去「长按桌面 → 小组件列表 → 拖拽」的繁琐流程。因 v1.3.3 已移除配置页，钉上去即直接显示全部未完成待办。当前 Launcher 不支持一键添加时，会提示改为手动长按桌面添加。
- **v1.4.1**：修复「＋桌面」点了没反应——部分国产桌面会静默忽略 pinning 请求（不弹确认框、也无回调）。改为监听 successCallback + 3 秒超时兜底，被忽略时自动弹出「手动添加」引导。

### v1.5 新增

- **批量导入**：右上角「⋮」→「批量导入」，粘贴多行文本（每行一条）+ 选分类，一键建多条待办
- **导出列表（可读文本）**：「⋮」→「导出列表」，把当前待办导出成 .txt 清单并调起系统分享，便于直接查看 / 发微信 / 迁到别的 App（区别于 JSON 备份）
- **复制单条**：每条待办右侧「📋」按钮，点一下把标题复制到剪贴板

### v1.6 新增

- **周期性待办**：添加 / 编辑时可设「每天 / 每周 / 每月」。勾选完成时**不标记已完成**，而是自动顺延到下一个周期并保持未完成（提示「已完成，顺延至 MM-dd」），列表里永远只有一条、不会每天堆出历史已完成项；提醒闹钟同步重排。列表与桌面小组件都显示 🔁 标记
- **桌面小组件分类筛选（回归，换了更稳的做法）**：不再依赖系统的 `android:configure` 配置页（国产 Launcher 兼容性差，是「无法添加小部件」的主因），改为 App 内「⋮」→「小组件设置」：可设「新组件默认显示哪一类」，也能给每个已添加的组件单独指定分类。保存后该组件只显示对应分类，标题变成「小脑 · 学习」
- 批量导入支持统一设周期；JSON 备份与文本导出也带上了周期字段
- 数据库升到 **version 4**（新增 `repeat` 列，逐列检测迁移 + fallback 兜底，覆盖安装不丢数据）

### v1.7 新增（编辑能力增强）

- **编辑入口更明显**：每条待办右侧新增 **✏️** 按钮，点一下直接进编辑（原先只能靠「点整行」才触发，很容易发现不了）。点整行编辑依然保留
- **备注字段**：编辑弹窗里新增「备注（可选）」多行输入框，可写补充说明 / 链接 / 步骤。列表里备注显示在标题下方（灰色小字），**桌面小组件里也会显示一行**（没写备注时自动隐藏，不占高度）
- 现在一条待办可编辑的字段：**标题 / 备注 / 分类 / 到期 / 重复周期 / 置顶**
- JSON 备份与文本清单导出都带上了备注；数据库升到 **version 5**（新增 `note` 列，同样逐列检测迁移 + 兜底）

### v1.8 新增（滑动删除改为「确认式」）

- **滑动删除不立即删**：在列表项上向左滑动，行会停在「打开」状态并露出红色「🗑 点击删除」按钮，露出后**点按钮才真正删除**。避免手滑误删——以前是一滑过阈值就直接删，现在多了一道确认。
- **点其它地方自动收起**：某行滑开露出删除按钮后，点别的任意行或列表空白处，该行会**自动收起还原**原位；再点一次该行才进入编辑。避免一直停在打开态。
- 想取消删除：把行往回滑（或滑回原位）即可归位，不会触发删除。
- 删除后仍然保留「撤销」提示（底部 Snackbar），误点也能一键恢复。

### v1.9 新增（时间轴 / 统计 / 提醒可视化）

- **三种视图切换（顶部 Tab）**：列表 / 时间轴 / 统计，App 内一键切换，互不干扰。
- **日记时间轴**：按到期日期把待办串成竖向时间线（最近的在前），每天一个节点（圆点 + 日期 + 周几 + 贯穿竖线），右侧是该天的待办卡片；没有到期日的待办单独归到「未排期」放最后。点卡片进编辑。适合回顾每天 / 未来要做什么。
- **完成率统计**：顶部一个完成率圆环（已完成 ÷ 总数），下方列出「共 N 条 / 已完成 / 待完成 / 已逾期」关键数字，并给出每个分类（工作 / 学习 / 生活）的完成进度条，一眼看清执行情况。
- **提醒可视化**：设了到期时间的待办，列表里用 🔔 标记、逾期未完成用 ⏰ 标红；添加页明确提示「设置到期（到点提醒）」「⏰ 到点会通过系统通知提醒你」。到期提醒能力从 v1.1 起就在后台跑（精确闹钟 + 重启自动重排），这次把「会提醒」这件事在界面上做明显。

### v1.10 新增（删除更克制、更安全）

- **滑出的删除区只露一点**：左滑后不再整行铺满红色，只在右侧露出一条 **88dp 宽**的红色删除区（🗑 + 「删除」），其余保持列表原样，视觉更克制。
- **删除前先问一句**：点这条删除区不再直接删，而是弹出确认框「删除这条待办？」，确认才真删；点「取消」或直接关闭，行会**自动收起还原**。
- **顺手修好**：此前「点列表空白处」不会让已滑开的行收起（只有点别的行才会），现在点空白、点别处、取消删除都能让行归位。
- 确认删除后仍保留底部「撤销」提示。

## 如何运行（推荐：Android Studio）

1. 用 **Android Studio（Hedgehog 及以上）** 打开 `XiaoNao` 这个文件夹。
2. 首次打开会提示安装 Android SDK / 构建工具，按提示点「Sync」即可（Android Studio 会自动搞定）。
3. 连上手机（开 USB 调试）或开模拟器，点工具栏的 ▶ Run。
4. 装好后：
   - 在 App 里添加几条待办；
   - 长按手机桌面空白处 → 「小组件」→ 找到 **小脑** → 拖到桌面；
   - 在桌面上点待办左边的「○ / ✓」即可勾选完成，点标题打开 App。

## 如何自己构建 APK（命令行，可选）

需要本机已装 Android SDK 且 `ANDROID_HOME` 指向它：

```bash
cd XiaoNao
./gradlew assembleDebug        # 产物在 app/build/outputs/apk/debug/app-debug.apk
```

> 工程已验证可成功编译：在沙箱（腾讯 Android SDK 镜像 + Gradle 8.9）里跑通了 `assembleDebug`，
> 产出 `app-debug.apk`。若你本机有 Android Studio，直接打开本文件夹 Sync 即可。

## 直接装 APK（最快，不用装开发环境）

已编译好的安装包（带版本号）：

- **`/workspace/小脑_v1.10.apk`**（debug 签名版，包名 `com.example.xiaonao`，Android 5.0+ 可装）
- 历史版本：`小脑_v1.9.apk`、`小脑_v1.8.apk`、`小脑_v1.7.apk`、`小脑_v1.6.apk`、`小脑_v1.5.apk`、`小脑_v1.4.1.apk`、`小脑_v1.3.3.apk`、`小脑_v1.2.apk`、`小脑_v1.1.apk`

手机安装步骤：

1. 把 `小脑_v1.10.apk` 传到手机（微信文件传输 / USB 拷贝 / 网盘都行）；
2. 手机「设置 → 安全」打开「允许未知来源应用安装」（装完可关）；
3. 点开 apk 按提示安装；
4. 装好后：进 App 加几条待办 → 长按桌面空白处 →「小组件」→ 找到 **小脑** 拖到桌面即可；
5. 想让某个组件只看某一类：App 内「⋮」→「小组件设置」里指定分类。

## 应用内「点一下就能更新」（免费 GitHub 方案）

不用第三方账号、零成本：App 启动时（每天最多自动查一次）或手动点「⋮ → 检查更新」，去 GitHub 仓库拉 `update/latest.json`，
发现远端 `versionCode` 比本地大，就下载 APK 并调起系统安装器。

**发布一次更新的步骤：**

1. 在 `app/build.gradle` 把 `versionCode` +1、`versionName` 改成新号；
2. 编出 APK（debug 或你固定的一把发布密钥签名），改名成 `小脑_vX.Y.apk`；
3. 在 GitHub 上 **Draft a new release**，tag 写 `vX.Y`，把 APK 作为附件上传并发布；
4. 把 `update/latest.json` 改好提交：
   ```json
   {
     "versionCode": 15,
     "versionName": "1.9",
     "apkUrl": "https://github.com/<你的用户名>/<仓库名>/releases/download/v1.9/%E5%B0%8F%E8%84%91_v1.9.apk",
     "note": "本次更新内容…"
   }
   ```
5. 用户下次打开 App（或手动检查）就会看到「发现新版本」，点「立即更新」下载安装。

**注意事项：**

- `AppUpdater.kt` 顶部的 `UPDATE_JSON_URL` 必须改成你自己的仓库路径（`raw.githubusercontent.com/.../update/latest.json`）。
- **签名必须一致**：升级包要和已装 App 同一把密钥，否则报「签名冲突」装不上。正式分发前固定一把发布密钥，别再用 debug 密钥长期发。
- APK 文件名含中文，`apkUrl` 里要 URL 编码（或用 Release 附件的下载直链，从发布页「复制链接」即可）。
- Android 8+ 首次更新会引导你去设置开启「允许安装未知应用」；Android 12+ 系统安装器一定会弹确认，无法完全静默。

## 已知小限制

- 桌面小组件依赖 Android 系统，部分定制 ROM（如 MIUI / HarmonyOS）长按添加入口位置不同，但都支持标准 AppWidget。
- 图标为自适应图标（API 26+ 最佳显示），更低版本会显示纯色占位图标，不影响使用。
